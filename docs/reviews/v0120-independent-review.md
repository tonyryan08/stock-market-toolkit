# Independent review — v0.12.0 (week 10: the tutor bot on the course notes; the Graham ∩ Carver watchlist)

**Reviewed:** the public repository at commit `8af0afa` (v0.11.1) with the week-10 shipment laid over it — 34 paths, a fresh clone, the builder's working copies and conversation out of bounds. **Date:** 11 Nov 2026. **Brief:** `_REVIEW-BRIEF-WEEK-10.md`. **Rule:** findings only; nothing in the tree was changed except this file; the probes, the stub Messages API and the mutation harness lived outside the project and the throwaway `.dev.vars` and local D1 state were deleted when done (`git status --short` lists the same 34 paths as at the start plus this report; every shipped path is byte-identical to its checksum taken before the mutations).

## Verdict

**Ship with changes.** The week is built the way the record says it is: one shared Messages call, a bound prompt, a check that runs on every answer, a page that renders every outcome, a gate that reads the two existing rules and invents nothing, and a seed that is exactly what the chunker makes of the files in the tree today (194 passages, 0 rows differ). The FTS5 index ran on the local D1 and the fallback is pinned to take over when the index throws; nine of the ten gold questions retrieve a passage from the section the gold set names, eight of them first; the mutation harness killed 33 of 43 mutations. One thing the record promises is not true of one of the two documented entry points: **`POST /api/tutor` returns a withheld answer in full** — the page withholds the tip, the JSON hands it back (F1). The other findings are cheap: the number check does not read a decline's reason or the check line (F2), an uncited paragraph passes clean (F3), the daily cap is a read-then-insert that a burst of parallel questions walks through (F4), the watchlist prints a literal `${SIGNAL_RULE.minMatureDays}` once every small cap has matured (F5), one gold question's named passage is not retrieved and the pinned test cannot see it (F6), the course's own `P/E` cannot be asked about (F7), and the week-6 advice net withholds a correct second-person answer that uses the course's verb "hold" (F8).

Counts: **1 must · 8 should · 16 notes · 11 housekeeping items.** 43 mutations, 33 killed, 10 survived (one equivalent).
